# PaperScan 隱私說明

預設情況下，影像、原圖、角點、處理參數與 OCR 結果留在瀏覽器 IndexedDB。沒有設定 AI 時，程式不會對外傳送掃描影像。Gemma 分析和影像修復都需要使用者自行填入端點與金鑰，並在影像修復前明確勾選上傳同意。

API 金鑰只在目前工作階段記憶體中使用。使用者若主動勾選記住金鑰，仍需自行承擔瀏覽器端儲存風險；本產品不會把金鑰寫入 GitHub Pages bundle、URL、PDF、匯出資料或 console。

所有修復都建立在目前頁面的處理版本上，原始頁面仍保存在本機工作階段。AI 文字回答不會被當作像素修復結果，也不會用來生成文件內不存在的文字、數字、印章或簽名。
